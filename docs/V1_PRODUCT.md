Talent Coverage Matrix

Volunteer skills

- Coverage Score

## Domain rows

- Volunteers entered
- Skills self-assessed
- Evidence links attached
- Availability captured
- Load limits set
- Assignments tracked
- Pod recommendations generated
- Skill-gap report exported

- Staffing plan
- Pod match sheet
- Skill-gap report

- Evidence for advanced skills
- Max load enforced
- Balanced pod coverage required
